⚠️ COMMON ERRORS
═══════════════════════════════════════════════════════════════════

❌ "Permission denied"
→ Token missing required scopes
→ Add: repo, workflow permissions

❌ "Authentication failed"
→ Token incorrect or expired
→ Regenerate new token

❌ "Resource not accessible"
→ Token lacks specific permission
→ Add: Actions, Contents, PRs, Workflows
