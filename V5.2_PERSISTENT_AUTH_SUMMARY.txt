🔐 SECURITY

⚠️ IMPORTANT WARNINGS:

1. COOKIES = PASSWORDS
   • Có cookies = có quyền truy cập
   • Giống như username + password
   • PHẢI bảo mật tuyệt đối

2. NEVER COMMIT TO GIT
   • .gitignore đã được cấu hình
   • Không bao giờ commit selenium_cookies/
   • Không share cookies với ai

3. FILE PERMISSIONS
   Recommended:
   chmod 700 selenium_cookies/
   chmod 600 selenium_cookies/*.pkl

4. PRODUCTION
   • Sử dụng secrets manager
   • Encrypt at rest
   • Rotate sessions định kỳ

🎯 TECHNICAL DETAILS

How Chrome Profiles Work:
  --user-data-dir=/path/to/profile
  --profile-directory=Default
  
  Chrome saves:
  • Authentication cookies
  • Local Storage data
  • Session Storage
  • IndexedDB
  • Extension data
  • Form autofill
  • Browsing history

How Cookie Pickle Works:
  # Save
  cookies = driver.get_cookies()
  pickle.dump(cookies, open('file.pkl', 'wb'))
  
  # Load
  cookies = pickle.load(open('file.pkl', 'rb'))
  for cookie in cookies:
      driver.add_cookie(cookie)

Session Verification:
  driver.get('https://gemini.google.com/')
  if 'accounts.google.com' in driver.current_url:
      # Not logged in
      return False
  else:
      # Already logged in!
      return True

📊 SESSION LIFETIME

Google (Gemini):

  • Auto-renewal: Yes (khi sử dụng)

  • Typical lifetime: 30 days
  • Auto-renewal: Yes
  • 2FA: Recommend app authenticator

🛠️ TROUBLESHOOTING

Problem: "Session expired"
Solution:
  python3 setup_ai_login.py gemini  # or grok

Problem: "Cookies not loading"
Check:
  ls -la selenium_cookies/
  
Fix:
  chmod 600 selenium_cookies/*.pkl

Problem: "Chrome profile corrupt"
Reset:
  rm -rf selenium_cookies/chrome_user_data/
  python3 setup_ai_login.py both

Check Status:
  python3 setup_ai_login.py status
