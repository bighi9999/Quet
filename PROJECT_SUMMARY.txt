========================================
📊 OVERVIEW
========================================

Một ứng dụng web hoàn chỉnh sử dụng AI (GPT-4 Vision & DALL-E 3) 
để phân tích ảnh sản phẩm và tạo ảnh mới từ prompt AI-generated.

Live Demo: http://14.225.210.195:3000
(Server tạm thời - xem hướng dẫn deploy cho production)

========================================
✨ FEATURES
========================================

✅ Upload ảnh (drag-drop hoặc browse)
✅ Phân tích ảnh bằng GPT-4 Vision
✅ Tự động tạo 3 prompts sáng tạo
✅ Sinh ảnh mới bằng DALL-E 3
✅ So sánh ảnh gốc vs AI side-by-side
✅ UI responsive đẹp mắt
✅ Error handling hoàn chỉnh
✅ Security best practices

AI Services:
