🆘 TROUBLESHOOTING - XỬ LÝ LỖI THƯỜNG GẶP
═══════════════════════════════════════════════════════════════════

❌ "No API key provided"
   → Fix: Nhập OpenAI API key vào ô input trên webapp

❌ "Failed to analyze image"
   → Nguyên nhân: API key sai, hết quota, hoặc network timeout
   → Fix: 
      1. Kiểm tra API key có đúng không
      2. Check billing trên https://platform.openai.com/account/usage
      3. Thử lại sau vài giây

❌ "Image too large"
   → Nguyên nhân: File > 10MB
   → Fix: Resize ảnh trước khi upload

❌ Server không chạy
   → Check: curl http://localhost:3000/api/health
   → Fix: cd /home/root/webapp && node index.js

❌ Port 3000 bận
   → Check: lsof -i :3000
   → Fix: kill -9 <PID> hoặc đổi port: PORT=8080 node index.js

❌ Public URL không hoạt động
   → Nguyên nhân: Sandbox network limitations
   → Fix: Deploy lên Render.com/Railway.app để có stable URL

❌ Dark mode không save
   → Nguyên nhân: localStorage disabled hoặc private browsing
   → Fix: Dùng normal browser mode (không incognito)

❌ History không hiện
   → Nguyên nhân: Chưa có analyses nào, hoặc localStorage cleared
   → Fix: Phân tích vài ảnh trước, history sẽ tự động xuất hiện
