✨ NEW FEATURE: SELENIUM LIVE VIEW

🎯 Mục Đích:
   Hiển thị real-time các bước Selenium automation ngay trên webapp,
   giúp người dùng thấy được quá trình phân tích đang diễn ra như thế nào.

═══════════════════════════════════════════════════════════════════

🎬 TÍNH NĂNG CHÍNH

1. 📺 FLOATING WINDOW
   • Cửa sổ nổi góc dưới phải màn hình
   • Kích thước: 400x500px (desktop)
   • Responsive trên mobile
   • Slide-in animation mượt mà

2. 🎨 VISUAL DESIGN
   • Gradient background: #1e3c72 → #2a5298
   • Color-coded actions:
     - ✅ Success (Green)
     - ❌ Error (Red)
     - ⚠️ Warning (Orange)
     - ℹ️ Info (Light Blue)
   • Emoji icons cho mỗi action type

3. ⚡ TOGGLE BUTTON
   • Button tròn 60x60px
   • Badge đếm số actions mới
   • Bounce animation khi có hoạt động
   • Sticky position bottom-right

4. 📊 ACTION LOG
   • Hiển thị 20 actions gần nhất
   • Timestamp cho mỗi action
   • Auto-scroll to newest
   • FIFO buffer management

5. 🎮 CONTROLS
   • 🗑️ Clear button: Xóa log
   • ✕ Close button: Ẩn window
   • Click toggle: Show/hide

🔧 TECHNICAL DETAILS

Frontend (v5.html):
  • +200 lines CSS cho styling
  • Floating position với z-index 1000
  • CSS animations (slideInUp, pulse, fadeInLeft, bounce)
  • Mobile responsive breakpoints

Frontend (v5-selenium.js):
  • State management cho Live View
  • addSeleniumAction() - Log actions
  • updateSeleniumView() - Render UI
  • showSeleniumSteps() - Predefined sequences
  • Badge counter logic
  • Auto-show toggle button

Integration:
  • Tích hợp vào analyzeWithSelenium()
  • Log mỗi bước tự động
  • Error handling
  • No backend changes required

⚡ PERFORMANCE

Bundle Size: +3KB (minified CSS + JS)
Memory Usage: ~50KB for 20 actions
CPU Impact: Negligible (CSS animations)
Network: 0 (client-side only)

Optimization:
  • FIFO buffer (max 20 actions)
  • CSS transforms for animations
  • Debounced scroll
  • Lightweight DOM updates
